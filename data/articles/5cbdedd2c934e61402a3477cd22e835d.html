【通知】第二届重要传染病智能预测挑战赛（“2026-9中国季节性流感流行分支及流行株预测比赛”）诚邀各界参赛

中国生物物理学会中国生物物理学会官方澎湃号
2026-09-17 18:34
北京

传染病始终是人类健康和全球公共卫生安全的重大威胁，深刻影响着人民健康、社会稳定与经济发展。当前，人工智能、大数据与生物信息技术的深度融合正为传染病防控带来革命性突破。为践行《“健康中国2030”规划纲要》和《关于建立健全智慧化多点触发传染病监测预警体系的指导意见》，推动流感监测数据、人工智能与公共卫生实践的深度融合，2025年，中国生物物理学会生物医学信息分会联合多部门与学术团体举办了重要传染病智能预测挑战赛。

今年，“2026-9中国季节性流感流行分支及流行株预测比赛”报名启动，截止日期为2026年10月8日，诚邀各高校、科研院所、疾病预防控制机构、医疗卫生机构及相关单位积极参赛，共创AI驱动传染病防控高质量发展新局面。

比赛背景

01

在众多重要传染病中，季节性流感是最具代表性的范例之一，它由流感病毒引发，在全球范围内具有高度传播性和周期性流行特点，造成严重的公共卫生和经济负担。季节性流感由多种流感病毒共同引起，目前包括甲型H3N2、甲型H1N1和乙型Victoria。中国幅员辽阔，南、北方省份每年冬春季存在季节性流感流行高峰，而南方省份夏季也常出现流感高发流行。由于流感病毒 RNA 依赖性聚合酶缺乏校对功能，基因组突变率较高（尤其是表面蛋白），频繁发生抗原漂移，导致新的流行株不断涌现并引发流行传播。因此，及时准确地预测未来流行株，对于把握变异株动向、筛选候选疫苗株、确定疫苗更新策略以及制定季节性流感防控策略至关重要。

比赛内容

02

预测目标为未来半年中国A/H3N2、A/H1N1及B/Victoria三个亚型的流行分支和流行株。

预测任务

03

针对中国大陆地区季节性流感（涵盖A/H3N2、A/H1N1及B/Victoria三个亚型），参赛者需于每年9月份预测未来半年的流行分支和流行株。本次比赛为“2026-9中国季节性流感流行分支及流行株预测比赛”。

具体任务为：基于各公共数据库（包括但不限于GISAID、GenBank等）的季节性流感病毒血凝素（HA）核酸或蛋白序列数据（可以使用全球流感序列数据，也可以叠加利用任何其它类型公开数据），预测三个亚型各自哪个分支将成为中国大陆地区未来半年的流行分支，以及哪株病毒将成为流行株。中国国家流感中心会向公共数据库提供我国季节性流感病毒序列数据以供使用（数据截至9月19日，Submitting Laboratory选定[China, Beijing] WHO Chinese National Influenza Center）。考虑到中国国家流感中心提交的毒株序列对中国季节性流感流行株的代表性相对较好, 预测流行株的选定范围以中国国家流感中心上传至GISAID的毒株为主，也可以选定其他国家和地区的代表性毒株。

排位鼓励

04

1. 评分体系

每个亚型（A/H3N2、A/H1N1、B/Victoria）分别评分。每个亚型的评分为两项分数之和，其中分支一致性分数S_clade与序列一致性分数S_seq各占 0–1 分。分数越高表示预测越好：

S = S_clade + S_seq，S ∈ [0, 2]

2. 分支一致性分数

分支一致性分数计算方法：统计未来半年(2026.10.01～2027.03.31）真实流行株集合中，属于预测分支（采用Nextclade分支定义，优先使用subclade，无subclade时使用clade，以专家审定为准）的毒株数量，占全部真实流行株总数的比例。该分数评估预测分支是否为未来半年主要流行的进化分支；占比越大，分数越高。

设预测分支为c* ，未来半年中国大陆真实流行株集合为 {s_1, s_2, …, s_N} ，共 N 株。则

S_clade = (1/N) · Σ(i=1→N) I{ c(s_i) = c* }

其中 I{·} 为示性函数（条件成立取 1，否则取 0），c(s_i)为毒株 s_i 所属的 Nextstrain分支。S_clade即未来流行株中落入预测分支的频率。显然 0 ≤ S_clade≤ 1；当全部流行株都属于预测分支时取 1。

3. 序列一致性分数

将预测流行株的 HA 氨基酸序列与真实流行株集合中每条序列逐一比对，计算氨基酸相似性；再以每条序列在集合中的数量占比（流行程度）为权重做加权平均。该分数刻画预测流行株与实际流行毒株在氨基酸序列水平上的整体匹配程度，权重设计使高频流行株对得分贡献更大。

设真实流行株集合去重后有M条不同序列{x_1, x_2, …, x_M}，第j 条序列的数量为n_j，其占比（权重）为

w_j = n_j / Σ(k=1→M) n_k，且 Σ(j) w_j = 1

预测株s*与序列x_j的氨基酸相似性定义为

sim(s*, x_j) = 1 - d_AA(s*, x_j) / L

其中 d_AA(s*, x_j) 为两序列 HA 氨基酸比对中不一致位点（含错配与空位）的数目，L为比对长度。序列一致性分数为相似性的流行度加权平均：

S_seq = Σ(j=1, j=M) sim(s*, x_j) · w_j

因 0 ≤sim(·)≤ 1 且权重和为 1，故 0 ≤ S_seq≤ 1；当预测流行株与当季全部流行株序列完全一致时取 1。

4. 排位与鼓励

分别计算三个亚型的得分，将三个亚型得分相加得到总分，按总分从高到低排位。排位第1为第一赛道，排位2-3为第二赛道，排位4-6为第三赛道，获得相关技术排位证书及人民币2000元、1000元及500元鼓励。
